Parte 01 • Fundamentos de agência

O que torna algo um agente?

A diferença central não é “ter IA”. É quem escolhe o próximo passo quando o contexto muda.

01 • Automação

A → B → C

O caminho já nasce definido. Se algo foge do esperado, o fluxo normalmente quebra ou para.

Exemplo: enviar e-mail sempre depois do formulário.
02 • Workflow dinâmico

A → condição → B/C

Há ramificações, mas os caminhos possíveis foram desenhados antes.

Exemplo: se orçamento < R$ X, sugerir hotel econômico.
03 • Agente

state + goal → action

O sistema usa estado, objetivo e feedback para decidir a próxima ação.

Exemplo: hotel lotado → buscar alternativa → pedir aprovação.
Pergunta para a turmaem qual desses casos existe decisão em runtime?
Use essa lente ao longo da aula: quem decide o próximo passo?03

O agente age sobre o mundo e o mundo responde

Observação ≠ Estado

O agente raramente vê o mundo inteiro; ele decide com base na representação que construiu.

Exemplo da viagem

Hotel indisponível muda o plano

O agente não apenas falha: ele observa o resultado, atualiza o estado e escolhe uma nova ação.

Quando o espaço de ações cresce, a decisão individual vira problema de coordenação.05

Coordination patterns

Multi-agent não é “vários agentes”; é coordenação

Depois que a tarefa é dividida, a pergunta vira: quem decide quem faz o quê?

Dynamic workflows

Quem decide o próximo passo?

Patterns deixam o controle de fluxo mais fácil de enxergar. A pergunta é se o caminho está pré-definido ou se emerge em runtime.

Eixo de controle

Static

A → B → C

Conditional

Dynamic

state → choose next
design timeruntime
Sequential

A → B → C

Bom quando a dependência entre etapas é clara.

Routing

Input → R → ?

Bom quando diferentes casos exigem caminhos diferentes.

Parallel

A ⇢ B,C,D ⇢ Σ

Bom quando subtarefas podem acontecer ao mesmo tempo.

Orchestrator

Plan → Workers

Bom quando a decomposição surge durante a execução.

Regra prática:quanto mais incerteza, mais valor tem decisão em runtime.
Patterns são mecanismos de controle, não o foco da aula.14

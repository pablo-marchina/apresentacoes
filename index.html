COMO O COMPORTAMENTO MUDA

A arquitetura define como o agente escolhe o próximo passo

O mesmo loop pode produzir comportamentos muito diferentes dependendo de estado, horizonte de decisão e liberdade de ação.

REACTIVE

Observe → Act

Rápido e local; reage ao presente.

MODEL / GOAL

State + Goal

Mantém representação e escolhe ações orientadas ao objetivo.

DELIBERATIVE

Compare → Decide

Antecipa alternativas, consequências e trade-offs.

UTILITY

Trade-offs

Tempo, custo, risco e qualidade diferenciam caminhos válidos.

PLANNING & REPLANNING
Plan → Act → Observe → Replan

O trade-off é commitment ↔ adaptability: manter o plano quando ainda faz sentido e revisá-lo quando o ambiente muda.

BOUNDED AUTONOMY
Capability ≠ Permission

Action space define o que é possível; boundaries definem o que é permitido: permissions, budgets, timeouts, max steps e aprovação humana.

Esses conceitos preparam o problema de decompor trabalho sem substituir a seção de Multi-Agents.05

WORKFLOW PATTERNS

A pergunta central: quem decide o próximo passo?

Patterns organizam execução. O grau de dinamismo aumenta à medida que mais decisões saem do design time e passam para runtime.

SEQUENTIAL

A → B → C

Caminho conhecido previamente.

ROUTING

A → Router → ?

Entrada ou state escolhem o próximo caminho.

PARALLEL

Fan-out / Fan-in

Trabalhos independentes executam e convergem.

ORCHESTRATOR

Plan → Workers

Subtarefas e responsáveis podem surgir em runtime.

Static → Conditional → Dynamicdesign-time control ─────→ runtime control
Workflow dinâmico é uma dimensão de controle; não é sinônimo de agente.13
PRODUCTION SCENARIOS

Em produção, autonomia encontra o sistema real

O critério deixa de ser apenas “resolve a tarefa?” e passa a incluir recuperação, segurança e previsibilidade diante de falhas.

MODELO MENTAL FINAL

Agência decide. Multi-agent distribui trabalho. A2A padroniza a colaboração.

O comportamento nasce do ciclo observar → representar → decidir → agir. Produção adiciona controles, persistência e confiabilidade ao redor desse ciclo.
